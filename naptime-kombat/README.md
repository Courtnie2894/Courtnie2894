# Naptime Kombat

A one-file, 16-bit-style fighting game that doubles as a 404 page. Every baby fights Naptime, and Naptime always wins eventually.

## Use it as a 404 page

GitHub Pages serves a file named `404.html` at the root of a Pages site for any URL that doesn't exist.

1. Copy `404.html` from this folder to the root of the site's repo (for a user site, that's the `courtnie2894.github.io` repo).
2. Commit and push. Any broken link on the site now loads the game.

The file is self-contained. Its only outside request is the Press Start 2P font from Google Fonts, with a monospace fallback.

## Controls

- Arrows: crawl, flatten (down), bounce (up)
- Z: pat. X: bonk. S: block. H: move list. M: mute. Enter: confirm.
- Phones get an on-screen pad automatically.

## What happens

Pick a baby, then hold Naptime off. Each win only delays Naptime, and every round you start sleepier while Naptime comes back stronger. The Sandman ends the run, a goodnight roll call plays, and the end screen offers a rematch or a link home.
